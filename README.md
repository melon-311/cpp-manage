# 教务管理系统

基于 C++ 开发的命令行教务管理系统，支持**多角色登录**（管理员、学生、老师），实现人员管理、课程管理、成绩管理、数据统计等完整教务功能。

---

## 编译与运行

### 环境要求
- 支持 C++11 或更高版本的编译器（如 g++、VS）

### 编译命令
```bash
g++ manage.cpp -o manage
```

### 运行命令
```bash
manage
```
或直接双击 `manage.exe` 运行。

---

## 功能概览

### 管理员功能
- 学生、老师、课程信息的增删改查等

### 学生功能
- 查询本人成绩、查询课程信息等

### 老师功能
- 录入成绩、修改成绩等

### 统计功能
- 按班级统计成绩、按课程统计总体分数（平均分、最高/最低分、排名）等

  ###数据持久化
- 所有数据自动保存至文件，程序关闭后数据不丢失

### 其他
- 多角色权限分离、交互式菜单导航、数据持久化（文件读写）等

## 使用说明

### 默认登录账号

系统内置一个**管理员**账号，用于首次登录和录入基础数据：

| 角色 | 账号 | 密码 |
|---|---|---|
| 管理员 | `admin` | `123` |

### 登录与账号创建流程

1. 使用管理员账号 `admin` / `123` 首次登录
2. 管理员录入**学生**和**老师**信息后，对应的账号自动生成：
   - **学生登录账号**：学号，默认密码：`123456`
   - **老师登录账号**：工号/学号（系统分配），密码由老师**首次登录时自行设定**

> 注意：学生和老师必须先由管理员录入，才能登录系统。

### 运行后操作

运行程序后，首先选择登录角色（管理员/学生/老师），输入对应账号和密码即可进入系统，按菜单提示操作。
